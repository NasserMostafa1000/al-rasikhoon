# Al Rasikhoon Real Estate — الراسخون العقارية

Bilingual (AR/EN) marketing site with Al Watan Tower 3D, corridor walkthrough, Street View–style apartment tour, and Ask AI.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5180

Optional: copy `.env.example` to `.env` and set `VITE_ASK_API`.
